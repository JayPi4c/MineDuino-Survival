# MineDuino Survival

MineDuino Survival is an addon for the Minecraft Mod [MineDuino](https://github.com/JayPi4c/mineduino). While MineDuino
only adds blocks to the creative menu in order interact with an Arduino board using Serial Communication, MineDuino
Survival adds more blocks and items such that it is possible to properly obtain MineDuino blocks during survival
gameplay.

## Features

- Craftable MineDuino blocks
- New blocks and items to obtain during survival gameplay via world generation

## FAQ

**Q: Do I need to have an Arduino board to use this mod?**<br>
A: No, MineDuino Survival can be used without an Arduino board. However, to fully utilize the features of MineDuino,
you will need to connect an Arduino board to your computer.

**Q: Is MineDuino Survival compatible with other mods?**<br>
A: MineDuino Survival is designed to be compatible with MineDuino. However, compatibility
with other mods is not guaranteed and may vary depending on the specific mods being used.

**Q: Do I need to install MineDuino to use MineDuino Survival?**<br>
A: No, MineDuino Survival includes all necessary components of MineDuino and therefore also include MineDuino itself.
You do not need to install MineDuino separately.

**Q: What code do I need to upload to my Arduino board?**<br>
A: You can use the same code as you would with MineDuino. The code can
be found in the [MineDuino GitHub repository](https://github.com/JayPi4c/mineduino).
